ثانوية الجنان — حزمة جاهزة لتحويل موقع المدير العام إلى PWA بشعار المدرسة الأصلي

هذه حزمة تحديث لمستودع GitHub الموجود لديك:
https://github.com/jhsschool-tech/jinan-director-dashboard

خطوات الرفع:
1. احتفظ بنسخة احتياطية من index.html الموجود في GitHub (من Code > Download ZIP أو Git history).
2. افتح ملف ZIP المرفق وفك الضغط (لا ترفع ZIP نفسه إلى المستودع).
3. في GitHub افتح المستودع > Add file > Upload files، واسحب محتويات المجلد مباشرة إلى جذر المستودع؛ ليس مجلدًا فرعيًا.
4. اسمح باستبدال index.html الحالي بالنسخة المرفقة، ثم Commit changes.
5. لا تحذف ملفَي app.js وstyles.css الموجودين في المستودع؛ الحزمة تعتمد عليهما، ولم تعدّلهما.
6. بعد نجاح GitHub Pages افتح الموقع من Safari في iPhone:
   https://jhsschool-tech.github.io/jinan-director-dashboard/
7. Share > Add to Home Screen > Open as Web App > Add.
8. إذا بقيت الأيقونة القديمة، احذف اختصار الشاشة الرئيسية وأعد إضافته، وحدّث الصفحة.

هذه الحزمة تشمل:
index.html                 الواجهة الحالية بعد إضافة شعار المدرسة وإعدادات التثبيت
pwa-brand.css              تنسيق الشعار داخل القائمة الجانبية
manifest.json              اسم التطبيق وأيقوناته ومعلومات التثبيت
sw.js                      تخزين مؤقت لملفات الواجهة العامة فقط
logo.png                   شعار المدرسة الأصلي
icon-192.png               أيقونة 192
icon-512.png               أيقونة 512
icon-maskable-512.png      أيقونة Android ذات منطقة أمان
apple-touch-icon.png       أيقونة iPhone 180
favicon-32.png             أيقونة المتصفح

مهم:
- ملف app.js الحالي يحمّل البيانات من data/tasks.json؛ هذا الملف غير موجود في المستودع العام بحسب الفحص وقت إعداد الحزمة. يجب توفير الملف الصحيح منفصلًا لظهور المهام. الحزمة لا تنشئ بيانات وهمية.
- تثبيت الموقع لا يعني حماية الوصول؛ GitHub Pages موقع عام. لا تنشر بيانات موظفين أو متعلمين أو أسرار الدخول في المستودع.
- بيانات localStorage محفوظة محليًا على الجهاز الحالي، ولا تتزامن تلقائيًا بين الأجهزة.
- خاصية العمل دون إنترنت مقتصرة على ملفات الواجهة، وليست على بيانات المهام أو Google API.
- عند الرفع الجديد احتفظ بنسخة من المشروع الأصلي قبل استبدال index.html.
